Contact

Contact and corrections

Best route: email • Replies are best-effort, usually within a few days

Found a missing session, a corner that looks wrong, or a chart that will not render? Send the details below. This is a personal project, so there is no support desk and no guaranteed response time, but reproducible bugs and corrections that can be checked against the public data are looked at first.

Where to send it

  • soni.soni.parth@gmail.com Best for a data correction, a privacy question or a general note.
  • Open a GitHub issue Best for a reproducible bug in the analyzer, a chart, a table or the Pages function. The code is public.

What makes a report actionable

Include enough for the result to be checked against the public data:

  • The year, Grand Prix and session you were analyzing.
  • The share fragment from the address bar, if you have one: #y=…&m=…&s=…. It reopens the exact selection.
  • For a chart or table problem, the tab, the driver or team, and what you expected instead.
  • The browser and device, and a screenshot if the layout is involved.
  • For a missing session, whether OpenF1 has published it. The analyzer can only use what the API returns.

What not to send

Please do not send passwords, payment details, identity documents or other sensitive personal data. Nothing in this project needs them. The site has no accounts and no private case data, and it does not need your contact list or a copy of your browser profile.

Scope. The analyzer reports what public telemetry shows. It does not provide official timing, race results, betting advice or predictions, and it cannot change a result or a team's data.

Privacy

The analyzer calls OpenF1 directly from your browser and stores no analysis on a server. Email is processed by Gmail so it can be read and answered. See Privacy for the requests the page makes, local browser state and how to ask for a message to be removed.

F1 Session Analyzer is independent and unofficial, and is not affiliated with Formula 1, the FIA, any team or OpenF1.
